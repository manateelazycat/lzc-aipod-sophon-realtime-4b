## 1. 移植与测试环境概览

- **目标模型**：`adventists-ai/Sophon-Realtime-4B-Flash`（Apache-2.0，36 文件，12,999,734,621 bytes / ~12.1 GiB；Hugging Face 锁定提交 `ae4a8591d0ae4c3b3da0250a613828bc2435963b`，ModelScope 锁定提交 `9240b6021dde87d65857bb00b8b404077bafcdc3`）
- **推理后端**：`vLLM 0.30.0` + `vLLM-Omni 0.30.0` + `duplexjev-vllm 0.3.0` + `sophon-realtime-flash 1.4.0`（3-Stage 异步全双工流水线：Stage-0 4B Thinker BF16 -> Stage-1 12.5Hz Streaming Talker -> Stage-2 Code2Wav）
- **目标设备 1（AGX Thor）**：`192.168.1.113`（`lzc-pod-QQWKng`，NVIDIA Thor `sm_110`，122 GiB 统一内存，JetPack `7.2` / L4T `R39.2.0`，Nsight Systems `2025.6.3`）
- **目标设备 2（AGX Orin）**：`192.168.1.86`（`lzc-aipod-ipslmk`，NVIDIA Jetson AGX Orin `sm_87`，61.4 GiB 统一内存，JetPack `7.2.1` / L4T `R39.2.1`，Nsight Systems `2025.6.3`）
- **测试工具与负载**：`scripts/benchmark_sophon.py --warmup 2 --runs 5 --concurrency 2`（输入音频 `hello_zh.wav`，中文流式 `text+audio` 输出；每轮均校验 `ok_count` = 单路 `5/5`、并发 `4/4`）。
- **协议接口**：
  - [runtime/server.py](file:///home/andy/lzc-aipod-sophon-realtime-4b/runtime/server.py) 监听 `:18009`，提供 `/health`、`/metrics`（`aipod:prompt_tokens_total`、`aipod:generation_tokens_total`、`aipod:requests_total`、`aipod:work_total`）、`POST /v1/chat/completions` 与 `WebSocket /v1/realtime`。

### 2.3 Thor Nsight 内核级对比（R10 vs R0，无 MPS 同条件采集）

- **`cudaLaunchKernel`**：`42,780` 次（`458.4 ms`） -> **`21,500` 次（`234.7 ms`），减少 49.7%**（Stage-2 `enforce_eager=false` CUDA Graph + Inductor 接管逐算子发射）。
- **`cuLaunchKernelEx`**：`9,259` 次（`72.8 ms`） -> **`4,487` 次（`37.6 ms`），减少 51.5%**。
- **显存分配**：`cudaMalloc` `15` 次（`5.513 s`） -> `0` 次（转为 `cuMemCreate` `5` 次 `2.607 s`，**分配耗时降低 52.7%**）。
- **OS 线程同步**：`futex` 累计等待从 `2,025.5 s` 降至 **`748.1 s`（-63.1%）**；`epoll_wait` 从 `1,871.8 s` 降至 **`1,575.0 s`（-15.9%）**。
